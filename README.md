# OSvm-project
OS Virtual Memory Simulation Extension

To fulfill the requirements of an Operating Systems course project, we extended this Twitter scraper with a virtual memory page replacement simulator based on real Tweet ID access patterns.

The file vm_simulator.py simulates memory accesses using FIFO and LRU algorithms.
Access sequence is derived from real user Tweet IDs (as numeric values).
The simulator logs HITs and FAULTs and calculates hit rate.

python vm_simulator.py
